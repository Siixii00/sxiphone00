# 場景編輯器素材庫

## CC0 素材來源

請從以下網址下載素材並放入此資料夾：

### 1. Smallworld Graphics
- 網址：https://opengameart.org/content/smallworld-graphics-smallworld-allswf
- 檔案：smallworld_all.swf（需要用 Flash 反編譯工具提取圖片）
- 內容：建築、樹木、角色、UI 元素、地形

### 2. Town Tiles
- 網址：https://opengameart.org/content/town-tiles
- 檔案：town.png
- 內容：城鎮建築、道路、裝飾物
- 尺寸：32x32 像素

### 3. Old Frogatto Tile Art
- 網址：https://opengameart.org/content/old-frogatto-tile-art
- 檔案：frogatto-tiles.png
- 內容：森林、洞穴、地牢地形

### 4. Water and Land Map Tilesets
- 網址：https://opengameart.org/content/32x32-water-and-land-map-tilesets
- 檔案：water_land.png
- 內容：水域和陸地地形
- 尺寸：32x32 像素

### 5. RPG Tileset
- 網址：https://opengameart.org/content/rpg-tileset
- 檔案：rpg_tileset.png
- 內容：草地、水域、路徑、裝飾物
- 尺寸：32x32 像素

## 使用方式

1. 下載上述素材檔案
2. 將圖片檔案放入此資料夾（`apps/dating/assets/`）
3. 重新整理場景編輯器，素材會自動載入
