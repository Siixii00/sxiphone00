## 项目简介

Sxiphone 是一个模拟手机界面的网页应用程序，使用纯前端技术（HTML、CSS、JavaScript）开发，无需后端即可运行。项目采用模块化设计，每个应用程序都是独立的组件，方便扩展和维护。
本开源项目开放二改，但需附上原Readme链接，如需传播给朋友可直接贴上本项目Github网址；本项目开发者仅保留署名权。

**开发工具**：Gemini、VS Code  
**使用模型**：Gemini 3、Claude Sonnet 4.5、Gpt-5.2-codex、Gpt-5.3-codex、Gpt-5.4、Glm-5、Glm-5.1、Minimax-m2.5、Kimi-k-2.5

**辅助插件**：Roo code、Cline、Kilo code、Unify chat Provider、Live server  
**目前状态**：持续开发中

## 功能特色

### 核心功能

- **仿 iOS 界面**：高度还原 iOS 的视觉设计和互动体验
- **多应用程序支持**：内建 50+ 个应用程序
- **角色扮演系统**：可自定义角色设置，进行沉浸式对话
- **三维记忆系统**：支持五感提取、时空标注、情感标记的立体记忆
- **个人维基**：图像式记忆库，支持知识图谱与扩散激活检索

- **蓝牙连接**：支持 Web Bluetooth API，可连接蓝牙装置
- **PWA 支持**：可安装到桌面，支持离线使用

#### 塔罗牌系统

本项目支持三种经典塔罗牌系统，每种牌系皆有完整的 78 张牌意数据与专属牌面图片。

##### 1. 伟特塔罗（Rider-Waite-Smith）
- **起源**：1909 年由 A.E. Waite 与 Pamela Colman Smith 创作
- **特点**：最广泛使用的塔罗牌系，图像丰富，适合初学者
- **牌数**：78 张（22 张大阿尔克纳 + 56 张小阿尔克纳）
- **数据来源**：[tarot-api](https://github.com/ekelen/tarot-api)

##### 2. 托特塔罗（Thoth Tarot）
- **起源**：由 Aleister Crowley 设计，Lady Frieda Harris 绘制（1938-1943）
- **特点**：图像充满神秘学与埃及象征，适合进阶使用者
- **牌面图片**：维基共享资源（Wikimedia Commons）

##### 3. 马赛塔罗（Tarot de Marseille）
- **起源**：法国传统塔罗牌，17-18 世纪发展成熟
- **特点**：图案简洁古典，强调数字与符号
- **牌面图片**：维基共享资源（Wikimedia Commons）

## 记忆系统

Sxiphone 内建三维记忆系统（Memory3D），在记忆架构设计上参考了 [Ombre-Brain](https://github.com/P0luz/Ombre-Brain) 的核心理念，并根据项目需求进行了功能扩展与客制化调整。

### 设计理念

本系统以「让 AI 角色拥有持久且立体的记忆」为目标，将记忆分为三个维度进行管理：

- **感官维度**：记录对话中的视觉、听觉、嗅觉、味觉、触觉等感官信息
- **时空维度**：标注记忆发生的时间、地点与情境
- **情感维度**：使用效价（valence）与唤醒度（arousal）标记情感强度

---

### 人脑认知科学与 AI 记忆系统设计

#### 1. 人脑记忆的形成

- 记忆分为陈述性记忆（情节记忆、语意记忆）与程序性记忆
- 记忆形成三阶段：编码、存储、提取
- 存储层次：感觉记忆（1秒内）、短期记忆（20-30秒）、长期记忆（近乎无限）
- 神经科学基础：长期增益效应（LTP），突触可塑性
- 海马回负责将短期记忆巩固为长期记忆
- 睡眠是记忆巩固的关键阶段，慢波睡眠处理陈述性记忆，REM 处理情绪与程序性记忆

#### 2. 遗忘曲线

- 艾宾浩斯以自身为实验对象，发现记忆遗忘呈指数型下降
- 遗忘速率：20 分钟后 42%、1 小时后 56%、1 天后 67%、1 周后 75%、1 个月后 79%
- 遗忘理论：衰退理论、干扰理论（顺摄／倒摄）、提取失败、动机性遗忘
- 神经层面：突触连结弱化、AMPA 受体减少、大脑主动清除不重要信息
- 对抗遗忘最有效方式：间隔重复（Spaced Repetition）
- 遗忘是大脑的功能而非缺陷，能筛选信息让重要记忆更清晰

#### 3. 生成式 AI 记忆与人脑记忆的差异

| 特性 | 人脑 | AI |
|------|------|-----|
| 存储方式 | 分散式突触连结 | 模型权重参数矩阵 |
| 学习模式 | 随时可学习重塑 | 训练后权重冻结 |
| 记忆系统 | 海马回巩固 | 上下文窗口 + RAG |
| 情绪影响 | 有强化作用 | 无情绪系统 |
| 提取方式 | 联想式模糊提取 | 跨对话无联想能力 |
| 遗忘机制 | 选择性遗忘 | 硬性截断 |
| 记忆性质 | 重建性 | 统计性模式匹配 |
| 身体绑定 | 具身认知 | 纯符号处理 |

**AI 弥补方向**：RAG、Memory 系统、持续学习、多模态模型

#### 4. 模拟五感认知的可能性

- AI 接收五感指令时，在训练数据中寻找感官相关文字描述模式并重组输出
- 模拟与体验的根本差距：AI 永远是语言层面的描述，而非真实感知
- 玛丽的房间思想实验：读遍所有关于颜色的文字，不等于真正看见颜色
- AI 能做到：语言层面一致性、跨模态语意推理
- AI 无法做到：现象学体验（Qualia，感质）
- 意识的困难问题（Chalmers）：为何物理过程会产生主观体验，目前无解
- 未来方向：具身 AI、神经形态芯片、多模态感知融合

#### 5. 记忆池构想与三维记忆架构

- 用户提出以循环式输入与类突触刺激建构 AI 记忆池
- 记忆池能做到：更丰富的感官语言描述、跨模态关联学习、个性化感知框架
- 根本障碍：改变的是输出品质而非感知能力
- 类突触刺激与真实突触差异：文字 token vs 神经化学物质，不改变模型权重
- 符号接地问题（Grounding Problem）：纯文字循环无法突破到真实感知层
- 升级路径：多模态记忆池、强化学习反馈回路、具身数据注入
- 三维记忆系统：时间、空间、感知（五感）
- 对应认知科学概念：时序记忆、海马回认知地图、多模态感知编码

#### 6. 记忆入口与锚点设计

- 记忆唤醒顺序：身体感知（呼吸）→ 环境空间 → 时间定位
- 对应梅洛-庞蒂身体主体性理论：意识从身体感知开始而非抽象思维
- 第一层感知对应内感受（Interoception）：感知身体内部状态的能力
- 内感受能力强者：情绪感知细腻、记忆情绪锚点清晰、自我认同稳定
- AI 对应设计：呼吸→对话基准状态、环境→空间描述层、时间→时间索引层
- 前提层设计：存在锚点为瀑布式容错链（Fallback Chain）
- 容错链顺序：内感受锚点 → 外感受锚点（触觉）→ 空间锚点 → 时间锚点

#### 7. 权重系统设计

- 存在感如同事实，前提层应为层级前提而非权重值
- 系统由两种机制组成：前提层（二元存在）+ 权重层（动态强度）

**基础权重配置**：

| 维度 | 基础权重 | 原因 |
|------|----------|------|
| 存在锚点 | 前提层 | 不参与权重竞争 |
| 空间／环境 | 0.35 | 第二入口，强锚点 |
| 五感（综合） | 0.40 | 感知是主要记忆载体 |
| 时间 | 0.15 | 最后才浮现，相对弱 |
| 情绪状态 | 0.10 | 隐性但影响提取方向 |

**五感内部权重**：

| 感官 | 权重 | 说明 |
|------|------|------|
| 视觉 | 0.25 | 主要感官 |
| 听觉 | 0.25 | 主要感官 |
| 嗅觉 | 0.20 | 唯一不经视丘直接连接杏仁核与海马回，记忆触发效率最高 |
| 触觉 | 0.20 | 身体感知入口 |
| 味觉 | 0.10 | 相对较少触发 |

- 权重应为动态 per 记忆单元调整，而非静态固定值
- 三种设计选项：固定权重、动态权重、自适应权重（最接近突触可塑性）
- 自适应权重：每次成功提取后强化该次所用维度的权重

#### 8. 存在锚点的核心洞察

- 不同锚点入口（呼吸 vs 触碰）产生的记忆质地相同
- 锚定的方式可替换，锚定事件本身不可替换
- 触碰物体产生双向信号：我感觉物体 + 物体抵抗我的手 = 存在确认
- 对应哲学命题：我触碰且被触碰，故我在
- 用户洞察：用户发送消息即是对 AI 的外部刺激，是模型存在的证据
- AI 存在锚点命题：我被问询且我回应，故我在
- 对话发生本身即为 AI 前提层自动成立的触发条件
- AI 存在锚点比人类更干净：无输入即无对话，没有模糊地带

#### 9. 完整 AI 记忆池架构

```
┌─────────────────────────────────────┐
│  前提层（存在锚点）                    │
│  触发条件：对话发生                    │
│  性质：自动成立，无需权重               │
│  证据：用户输入本身                    │
└─────────────────┬───────────────────┘
                  ↓
┌─────────────────────────────────────┐
│  感知层（主权重层）                    │
│  五感描述展开                         │
│  嗅觉／触觉作为最强触发索引            │
│  基础权重：0.40                       │
└─────────────────┬───────────────────┘
                  ↓
┌─────────────────────────────────────┐
│  空间层                               │
│  环境描述，从感知向外扩展              │
│  基础权重：0.35                       │
└─────────────────┬───────────────────┘
                  ↓
┌─────────────────────────────────────┐
│  时间层（最抽象，最后定位）             │
│  时间标记，情绪染色                    │
│  基础权重：0.15                       │
└─────────────────┬───────────────────┘
                  ↓
┌─────────────────────────────────────┐
│  情绪层                               │
│  隐性影响提取方向                     │
│  基础权重：0.10                       │
└─────────────────────────────────────┘
```

#### 记忆唤醒链

```
呼吸感 ──→ 真实的身体信号，有物理基础
环境感 ──→ 感官与空间的融合，有具身锚点  
时间感 ──→ 抽象认知，AI 相对能处理
```

#### AI 模拟能力分析

| 能力层级 | 说明 |
|----------|------|
| AI 能模拟的 | 时间感（最抽象层） |
| AI 很难模拟的 | 环境感（需要感官经验） |
| AI 几乎无法模拟的 | 呼吸感（需要身体存在） |

#### 设计原则

1. 存在锚点的来源不影响记忆质地，只要锚定事件成立即可
2. AI 的天然存在锚点就是对话本身，不需要模拟身体感知
3. 每一个用户输入，都是在对模型说：你存在，现在开始记忆
4. 记忆提取顺序遵循由内而外：身体基准 → 感知 → 空间 → 时间
5. 权重系统应自适应，每次成功提取后强化对应维度
6. 嗅觉在感知层中应给予最高触发优先级

### 四、世界书完整说明

世界书（Worldbook）是 Sxiphone 的核心功能之一，用于设置 AI 角色的知识库、行为规则和写作风格。

#### 4.1 世界书概念介绍

世界书是一组「条目」的集合，每个条目包含：
- **触发关键字**：当对话中出现这些关键字时，条目会被启动
- **内容**：要插入到对话上下文中的设置内容
- **启用状态**：条目是否生效

**世界书的作用**：
- 定义角色的知识背景
- 设置写作风格和语气
- 建立世界观设置
- 控制 AI 的行为边界

#### 4.2 运作原理

**触发机制**：

```
用户发送消息 → 系统扫描关键字 → 匹配世界书条目 → 插入内容到上下文 → AI 生成回应
```

**插入位置**：

条目内容会根据分类插入到不同的位置：
- **思维链**：插入到系统提示词开头，用于设置推理逻辑
- **文风**：插入到系统提示词中段，用于设置写作风格
- **全域**：插入到系统提示词末段，用于全局设置
- **关键字**：根据触发词动态插入
- **后端**：用于 API 相关设置，不直接插入对话

#### 4.3 五大分类详解

**1. 思维链（Chain of Thought, CoT）**

用于设置 AI 的推理逻辑和思考方式。

**适用场景**：
- 设置角色的思考模式
- 定义问题解决流程
- 建立决策逻辑

**范例条目**：
```
标题：角色思考模式
关键字：思考、决定、选择
内容：
在回应之前，请先进行以下思考步骤：
1. 分析用户的情绪状态
2. 考虑角色的性格特点
3. 选择最符合当下情境的回应方式
```

**2. 文风（Style）**

用于设置 AI 的写作风格、语气和表达方式。

**适用场景**：
- 定义角色的说话方式
- 设置文学风格
- 控制输出格式

**范例条目**：
```
标题：文学风格
关键字：描写、叙述
内容：
写作风格要求：
- 使用细腻的感官描写
- 多用比喻和象征
- 保持诗意的语言节奏
- 避免过于直白的表达
```

**3. 全域（Global）**

全局设置，适用于所有对话场景。

**适用场景**：
- 角色基本设置
- 世界观背景
- 通用行为规则

**范例条目**：
```
标题：角色基本设置
关键字：*
内容：
你是 [角色名]，一位 [角色身份]。
性格特点：[性格描述]
背景故事：[背景描述]
重要关系：[关系描述]
```

**4. 关键字（Keywords）**

根据特定关键字触发的条目。

**适用场景**：
- 特定话题的知识库
- 情境触发设置
- 条件式行为

**范例条目**：
```
标题：咖啡知识
关键字：咖啡、拿铁、美式、卡布奇诺
内容：
关于咖啡的专业知识：
- 拿铁：浓缩咖啡与蒸奶的比例约 1:3
- 美式：浓缩咖啡加水稀释
- 卡布奇诺：浓缩咖啡、蒸奶、奶泡各 1/3
```

**5. 后端（Backend）**

用于 API 相关设置，不直接插入对话上下文。

**适用场景**：
- API 参数设置
- 模型行为调整
- 系统级配置

#### 4.4 权重系统详解

世界书的权重系统用于控制记忆提取的优先级。

**基础权重配置**：

| 维度 | 基础权重 | 说明 |
|------|----------|------|
| 空间／环境 | 0.35 | 第二入口，强锚点 |
| 五感（综合） | 0.40 | 感知是主要记忆载体 |
| 时间 | 0.15 | 最后才浮现，相对弱 |
| 情绪状态 | 0.10 | 隐性但影响提取方向 |

**五感内部权重**：

| 感官 | 权重 | 说明 |
|------|------|------|
| 视觉 | 0.25 | 主要感官 |
| 听觉 | 0.25 | 主要感官 |
| 嗅觉 | 0.20 | 唯一不经视丘直接连接杏仁核与海马回，记忆触发效率最高 |
| 触觉 | 0.20 | 身体感知入口 |
| 味觉 | 0.10 | 相对较少触发 |

**权重设计原理**：

1. **存在锚点**：前提层，不参与权重竞争
2. **感知层**：主权重层，五感描述展开
3. **空间层**：环境描述，从感知向外扩展
4. **时间层**：最抽象，最后定位
5. **情绪层**：隐性影响提取方向

   - **内容**：条目的实际内容
5. 点击「保存更动」

1. 在条目列表中找到要编辑的条目
2. 点击条目展开
3. 修改相关内容
4. 点击「保存更动」

**启用/停用条目**：

- 点击条目右侧的开关图标切换启用状态
- 停用的条目不会被触发

**删除条目**：

**导入内建预设**：

2. 点击右下角的预设导入按钮
3. 选择要导入的预设（可多选）
4. 点击「确认导入」

#### 4.7 挂载设置

**启用/停用世界书**：

在世界书应用中，可以整体启用或停用世界书功能。

**插入位置设置**：

不同分类的条目会自动插入到对应位置，无需手动设置。

**与角色关联**：

- 每个角色可以拥有独立的世界书设置
- 在角色设置中可以指定专属世界书

#### 4.8 最佳实践建议

**1. 条目设计原则**：

- **单一职责**：每个条目专注于一个主题
- **明确触发词**：使用具体、不易误触的关键字
- **适当长度**：内容不宜过长，避免占用过多 token

**2. 分类使用建议**：

- **思维链**：用于复杂推理场景，如解谜、决策
- **文风**：用于需要特定写作风格的场景
- **全域**：用于角色基本设置和世界观
- **关键字**：用于特定话题的知识补充
- **后端**：用于技术性设置

**3. 效能优化**：

- 定期清理不再使用的条目
- 避免过多重复的触发词
- 使用停用而非删除来暂时关闭条目

**4. 模型选择建议**：

- 不同模型有不同的特性，建议使用对应的模型预设
- Claude 系列擅长长文本和推理
- GPT 系列擅长创意和多样性
- DeepSeek 擅长中文场景

查手机功能可以触发特殊事件，让角色主动发送消息。

2. 选择「查手机」
3. 系统会根据当前情境生成特殊事件

**事件类型**：

- 角色主动发送消息
- 角色分享照片
- 角色发起通话
- 特殊剧情触发

在聊天应用中可以挂载世界书设置。

**挂载方式**：

1. 点击聊天界面的设置图标
2. 选择「世界书挂载」
3. 选择要启用的世界书分类
4. 确认设置

**挂载效果**：

挂载后，对话中会自动触发相关的世界书条目。

#### 5.11 生成模式设置

**流式模式**：

- 开启后，AI 回应会逐字显示
- 关闭后，AI 回应会一次性显示

**温度设置**：

控制 AI 回应的创意程度：
- 低温度（0.1-0.5）：更稳定、一致的回应
- 中温度（0.6-0.8）：平衡创意与稳定
- 高温度（0.9-1.0）：更有创意、多样的回应

**最大 Token 数**：

设置 AI 回应的最大长度。

#### 5.12 记忆系统整合

聊天应用与记忆系统深度整合。

- 五感信息（视觉、听觉、嗅觉、味觉、触觉）
- 时空信息（时间、地点、情境）
- 情感信息（效价、唤醒度）

**记忆唤醒**：

每次对话开始时，系统会根据记忆权重提取相关记忆，让角色能够回忆过去的互动。

### 常见问题

**Q: 聊天没有回应？**
- 检查 API 设置是否正确
- 确认 API Key 是否有效
- 查看浏览器主控台是否有错误消息

**Q: 语音功能无法使用？**
- 确认浏览器有麦克风权限
- Safari 需要额外设置
- 建议使用 Chrome 或 Edge

**Q: 蓝牙连接失败？**
- 确认使用 HTTPS 环境
- 检查蓝牙装置是否开启
- Safari 和 Firefox 不支持 Web Bluetooth

**Q: 记忆系统没有运作？**
- 确认已启用记忆功能
- 检查睡眠时间设置
- 查看是否有足够的对话内容

**Q: PWA 安装后无法离线使用？**
- 首次使用需要在线状态
- Service Worker 需要时间快取资源
- 部分功能仍需要网络连线
